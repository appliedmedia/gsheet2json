# Fixture Spreadsheet

Google's own sample financial data sheet, trimmed down. Used for all promo video recordings and manual QA sessions.

**URL:** https://docs.google.com/spreadsheets/d/15E8LvrzXeDy3ruj9AoM29Bh987sv1CQSDUKRC7moduo

Open this tab in Chrome before starting any recording session.

## Chrome window size for recording

**1500×1500** outer, positioned at (0, 31) on the LG 5K display (top-left, just below the menu bar). Browser chrome height is 121 px, so the recorded content area is **1500×1379** at screen offset (0, 152). Set via AX position/size at session start; `CROP_*` vars in `record-screen.sh` match these values.
